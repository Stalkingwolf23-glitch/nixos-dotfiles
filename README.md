## Overview
```
.
├── modules
│   ├── applications
│   ├── assets
│   ├── desktop
│   ├── editors
│   ├── gaming
│   ├── hosts
│   ├── lib
│   ├── networking
│   ├── overlays
│   ├── security
│   ├── style
│   ├── system
│   ├── terminal
│   ├── flake-file.nix
│   └── outputs.nix
└── flake.nix
```
- Top level `flake.nix`, input resolver from the inputs generated by tack and flake-parts
- `flake-file.nix` enables flake-file and flake-parts and contains core inputs (flake-parts, tack, home-manager and nixpkgs)
- `outputs.nix` defines the nixOS configuration while importing the directories
- `modules/` are where all the self contained modules live in, each group is then enabled by the host/user to be used in the system
