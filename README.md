# NixOS Dotfiles
Personal NixOS configuration and dotfiles managed with flakes.

## Features
- Declarative Setup
- Home Manager Integration
- Modular configuration structure

## Installation
```
git clone https://github.com/Stalkingwolf23-glitch/nixos-dotfiles.git
cd nixos-dotfiles
sudo nixos-rebuild switch --flake .#hostname
sudo nixos-rebuild switch --flake .#username
```
